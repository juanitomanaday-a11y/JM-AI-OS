# GOV-documentation-quality-standard.md — Documentation Quality Standard

**Status:** Draft. **Document type:** Governance.

Defines what quality means for an individual document. For repository-wide
structural quality, see `GOV-repository-quality-standard.md`.

## Purpose

To keep every document readable, complete, and consistent in style with
the rest of the repository.

## Scope

Applies to every document: SOPs, Templates, Reports, and Governance
Documents.

## Quality attributes

1. **Clarity** — plain language, short sentences, no unnecessary jargon.
2. **Consistency of style** — matches the tone and format already
   established in Batch 1: direct, imperative, minimal, table-driven
   where structured data is being defined.
3. **Completeness** — every section a document's type requires (e.g. an
   SOP's objective, prerequisites, procedure, per `docs/README.md`) is
   present.
4. **Correct terminology** — terms are used as defined in
   `GOV-glossary.md`; a document does not invent a new meaning for an
   existing term.
5. **Accurate cross-references** — see `GOV-cross-reference-standard.md`.
6. **No duplication** — a document does not restate content that already
   exists, authoritatively, in another document.

## Checking documentation quality

Checked during the Documentation Review Process
(`GOV-documentation-review-process.md`) before a document is approved.
