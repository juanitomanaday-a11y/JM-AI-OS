# GOV-glossary.md — Governance Glossary

**Status:** Draft. **Document type:** Governance.

Defines the terms used across the governance and documentation standards in
`docs/Governance/`. Every governance document uses these terms as defined
here. If a term is not defined here or in an existing Batch 1 document, do
not introduce a new meaning for it without adding it here first.

## Document types

| Term | Meaning |
|---|---|
| SOP | A standard operating procedure. Lives in `docs/SOP/`, named `SOP-<short-name>.md`. |
| Template | A reusable template. Lives in `docs/Templates/`, named `TPL-<short-name>.md`. |
| Report | A written or generated report. Lives in `docs/Reports/`, named `RPT-YYYY-MM-DD-<short-name>.md`. |
| Governance Document | A document defining a rule, standard, or process governing the repository or its documentation. Lives in `docs/Governance/`, named `GOV-<short-name>.md`. |

## Lifecycle terms

Full definitions: `GOV-documentation-lifecycle.md`.

| Term | Meaning |
|---|---|
| Draft | A document being written or revised. Not yet reviewed. |
| In Review | A document undergoing the Documentation Review Process. |
| Approved | A document JM has signed off on, per the Approval Process. |
| Published | An approved document that is live in the repository and in effect. |
| Maintained | A published document subject to ongoing upkeep. |
| Superseded | A document replaced by a newer version of itself or by another document. |
| Archived | A document kept for historical reference but no longer in effect. |
| Retired | A document formally removed from active use. |

## Change and review terms

| Term | Meaning |
|---|---|
| Change | Any addition, modification, or removal of content in the repository. |
| Minor Change | A change that does not alter meaning, structure, or governance status (e.g. wording, formatting). |
| Major Change | A change that alters meaning, structure, scope, or governance status of a document or the repository. |
| Documentation Review | Evaluation of a single document against the Documentation Review Process before approval. |
| Repository Review | Evaluation of the repository as a whole against governance standards. |
| Repository Audit | A formal, comprehensive check of the repository against every governance standard, producing a recorded outcome. |
| Repository Validation | A check that the repository's files, structure, and links meet defined validation criteria. |
| Approval | JM's formal sign-off on a change or document, recorded in `data/decisions.json`. |
| Release | A milestone point at which the repository's MAJOR version is incremented. |

## Relationship and reference terms

| Term | Meaning |
|---|---|
| Cross-Reference | A link or citation from one document to a specific location in another. |
| Document Relationship | A structural connection between two documents (governs, implements, related, supersedes). |
| Related Documents | The set of documents a given document depends on, implements, or is commonly read alongside. |

## Quality terms

| Term | Meaning |
|---|---|
| Documentation Quality | The clarity, completeness, and consistency of an individual document. |
| Repository Quality | The structural integrity and consistency of the repository as a whole. |
