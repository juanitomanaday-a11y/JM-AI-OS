# GOV-documentation-review-process.md — Documentation Review Process

**Status:** Draft. **Document type:** Governance.

Defines the standard for reviewing a single document before it is
approved. For reviewing the repository as a whole, see
`GOV-repository-review-process.md`.

## Purpose

To ensure a document is accurate, clear, and compliant with governance
standards before it becomes official.

## Scope

Applies to any document moving from Draft to Approved
(`GOV-documentation-lifecycle.md`).

## What a documentation review checks

1. Accuracy — the content is correct and does not conflict with
   `SYSTEM_RULES.md` or any other Published document.
2. Clarity — meets `GOV-documentation-quality-standard.md`.
3. Naming — meets `GOV-naming-convention-standard.md`.
4. Placement — the document is in the correct folder per
   `GOV-folder-structure-standard.md`.
5. Cross-references — links and citations are valid per
   `GOV-cross-reference-standard.md`.
6. No duplicated or conflicting concepts with existing Published
   documents.

## Review outcomes

1. **Pass** — the document proceeds to the Approval Process.
2. **Revise** — the document returns to Draft with noted issues.

## Who reviews

Any collaborator (JM or AI) may perform a documentation review. JM's
approval, separate from the review itself, is required before a document
is Approved (`GOV-approval-process.md`).
